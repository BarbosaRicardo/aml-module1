# Hyperparameter Optimization - study tools

Study aids for EN.705.742 Advanced Applied ML, Module 1.

Live: https://barbosaricardo.github.io/aml-module1/

- `playground/` - four interactive visualizations: gradient descent, particle swarm
  optimization, Bayesian optimization, early stopping
- `quiz/` - three practice quizzes, easy / medium / hard, ten questions each

Static HTML, no dependencies, no build step.
